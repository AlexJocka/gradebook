# GradeBook: АИС учёта успеваемости студентов

Учебный проект по дисциплине «Автоматизация процессов жизненного цикла программных средств» (Московский Политех), вариант «Приложение по учёту успеваемости студентов».

Полное техническое задание по ГОСТ 34.602-89: [docs/ТЗ_GradeBook.docx](docs/ТЗ_GradeBook.docx).

## Уточнённое задание

Система хранит:

- **контингент студентов**: ФИО, год поступления, форма обучения (дневная / вечерняя / заочная), учебная группа;
- **учебные планы**: специальность, дисциплина, семестр, количество часов, форма отчётности (экзамен / зачёт);
- **журнал успеваемости**: учебный год, семестр, студент, дисциплина, оценка.

### Функции

| Код | Функция | Роли |
|---|---|---|
| Ф1 | Количество студентов указанной формы обучения | администратор, методист |
| Ф2 | Количество часов и форма отчётности по дисциплине | все |
| Ф3 | Добавление и изменение студентов, групп, специальностей, дисциплин, учебных планов | администратор, методист |
| Ф4 | Добавление и изменение оценок в журнале успеваемости | администратор, преподаватель |
| Ф5 | Авторизация и управление пользователями | администратор |
| Ф6 | Обработка пользовательских исключительных ситуаций (хуки) | - |
| Ф7 | Журнал событий | администратор |
| Ф8 | REST API (OpenAPI на `/docs`), проверка работоспособности `/health` | - |

### Пользовательские исключительные ситуации

| Код | Ситуация |
|---|---|
| GB-001 | Дисциплины нет в учебном плане студента в этом семестре |
| GB-002 | Оценка не подходит к форме отчётности (экзамен: 2–5; зачёт: зачтено / не зачтено) |
| GB-003 | Запись о студенте, дисциплине и семестре уже есть |
| GB-004 | Операция над отчисленным студентом |
| GB-005 | Смена формы отчётности, когда по строке плана уже есть оценки |
| GB-006 | Недостаточно прав |
| GB-007 | Превышено число попыток входа |
| GB-008 | Объект не найден |

Для каждой ситуации операция откатывается, пользователь получает понятное сообщение (в API: HTTP 4xx и JSON с кодом), событие пишется в журнал, и вызываются зарегистрированные обработчики (хуки).

| `prod` | prod | + резервная копия БД, миграции, развёртывание на prod |
